# 🎮 Как включить GPU в Google Colab

## Шаг за шагом (на скриншотах):

### Шаг 1: Нажать меню "Runtime"
![Runtime меню](https://i.imgur.com/1a2b3c4.png)

Вверху слева в Colab, нажмите на слово **Runtime**

### Шаг 2: Выбрать "Change runtime type"
![Change runtime type](https://i.imgur.com/2b3c4d5.png)

Нажмите на **"Change runtime type"** (примерно 3-й пункт в меню)

### Шаг 3: Выбрать GPU
![Select GPU](https://i.imgur.com/3c4d5e6.png)

В диалоговом окне:
- Найти **"Hardware accelerator"** (внизу)
- Выбрать **"GPU"** из выпадающего списка
- Нажать **"Save"**

### Шаг 4: Дождаться перезагрузки
Runtime перезагрузится (это может занять 10-30 сек)

Когда готово, вернется обычный интерфейс Colab

### Шаг 5: Запустить код снова
Нажать **Ctrl+F9** (или кнопка "Run all")

Коды должны выполниться с GPU!

## ✅ Проверить что GPU включен:

После Save, запустить ячейку:

```python
# GPU Check
import subprocess
try:
    result = subprocess.run(['nvidia-smi'], capture_output=True, text=True)
    print("✓ GPU Available!")
    print(result.stdout[:500])
except:
    print("❌ GPU not available - try again")
```

Если видно информацию про GPU (например "NVIDIA T4" или "V100") - **GPU включен!** ✓

Если нет - повторить шаги выше.

---

## 🆘 Если не работает:

**Вариант 1: Перезагрузить Runtime**
- Runtime → Restart runtime
- Выбрать GPU снова
- Запустить код

**Вариант 2: Новый notebook**
- Создать новый notebook
- Сразу включить GPU (до запуска кода)
- Скопировать код туда

**Вариант 3: Проверить аккаунт**
- Google Colab бесплатный, но есть лимиты
- Если много использовал GPU → может быть блокировка
- Подождать несколько часов

---

## 📝 Важно!

⚠️ **GPU работает только в текущей сессии**
- Если закрыть браузер → runtime отключится
- Откройте notebook снова → выберите GPU снова

⚠️ **Есть лимиты**
- Google дает ~12 часов GPU в месяц бесплатно
- Если использовали много → придется ждать
- Для Colab Pro есть больше часов

⚠️ **T4 GPU (базовый) vs V100/A100 (быстрее)**
- Базовый T4 достаточен для демо
- Может быть очередь если много людей
