# Commands Guide

## Development

- `npm start`: Starts the proxy server.
- `npm run dev`: Starts the proxy server with nodemon for development.
- `npm test`: Runs `simple_test.js` to verify library/proxy.
- `npm run example`: Runs a sample chat completion using the library.

## Configuration

- Credentials should be placed in a `.env` file (see `.env.example` if exists, otherwise create one with `K2THINK_EMAIL` and `K2THINK_PASSWORD`).
